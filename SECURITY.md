# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| `0.1.1` | Yes       |
| `0.1.0` | Upgrade to `0.1.1` |

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities, data-corruption exploits, memory-safety/FFI bugs, or cryptographic issues.

Instead, report vulnerabilities privately through either of the following channels:

1. **GitHub Security Advisories** *(Recommended)*: Use the **Security -> Advisories -> Report a vulnerability** button on the [TejDb GitHub repository](https://github.com/YeabsiraBezabih/tej-db/security/advisories).
2. **Email**: Send an encrypted or detailed report to **yeabsirabezabih791@gmail.com** with `[SECURITY]` in the subject line.

### What to Include

- Affected crate(s) and version/commit hash
- Minimal reproduction steps, test case, or proof-of-concept
- Impact assessment (e.g., crash, torn-write data loss, FFI UB, authentication bypass, cryptographic weakness)

### Response Expectations

- Acknowledgment within **48 hours**
- Initial triage and severity assessment within **5 business days**
- Coordinated fix and advisory release prior to public disclosure
